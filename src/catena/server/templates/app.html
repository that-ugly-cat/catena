Place the references

The plan comes from the conversation: the assistant assembles it with citation_field, bibliography_field and document_prefs, and it is the same JSON the command line takes with --plan. Upload the manuscript, paste the plan, and you get a copy back with the field codes in place — then one Refresh in Word fills in the visible text and numbers a numeric style.

The upload lives in a temporary folder for the length of this one request and is deleted with it: nothing is stored here, which also means there is no second download. If you would rather the document never left your machine, the command line does the same job locally — see the user guide.
